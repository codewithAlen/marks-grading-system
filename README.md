# Student Grade Analyzer

This is a simple Python program that calculates the total, average, highest, and lowest marks of a student and assigns a grade based on the average.

## 🚀 Features
- Takes marks as input from the user
- Calculates total and average
- Finds highest and lowest marks
- Assigns grade (A, B, C, D)

## 💻 Technologies Used
- Python

## ▶️ How to Run
1. Download the file
2. Open in any Python editor
3. Run the program
4. Enter marks when prompted

## 📌 Output
The program displays:
- Total marks
- Average marks
- Highest and lowest marks
- Final grade
